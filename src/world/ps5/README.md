# Frozen original PS5 generator

Revision 5 / world 11 and all output-affecting dependencies are preserved here. Existing PS5 preset codes and damage saves continue to use this implementation. Do not refactor these modules with the current generator.

New islands use revision 7 / world 13: one generator with seed-driven coastline, relief and ecology variation, without preset selection. The revision change prevents old damage from attaching to a newly shaped island with the same numeric seed.
