# Visual asset credits

Scanned materials and branch/grass images are CC0, acquired from Poly Haven. Runtime images were converted to KTX2 with mipmaps; foliage alpha atlases were cropped and tree impostors baked from authored models.

- stone: [large_sandstone_blocks](https://polyhaven.com/a/large_sandstone_blocks) — CC0-1.0.
- wood: [medieval_wood](https://polyhaven.com/a/medieval_wood) — CC0-1.0.
- grass: [Leafy Grass by Charlotte Baglioni](https://polyhaven.com/a/leafy_grass) — CC0-1.0, 2m surface coverage.
- rock: [dark_rock](https://polyhaven.com/a/dark_rock) — CC0-1.0.
- soil: [forest_ground_04](https://polyhaven.com/a/forest_ground_04) — CC0-1.0.
- roof: [grey_roof_tiles](https://polyhaven.com/a/grey_roof_tiles) — CC0-1.0.
- bark: [pine_bark](https://polyhaven.com/a/pine_bark) — CC0-1.0.
- cloth: [rough_linen](https://polyhaven.com/a/rough_linen) — CC0-1.0.
- sand: [Coast Sand 01 by Rob Tuytel](https://polyhaven.com/a/coast_sand_01) — CC0-1.0.

Foliage: [Pine tree](https://polyhaven.com/a/pine_tree_01), [Jacaranda](https://polyhaven.com/a/jacaranda_tree), [Grass](https://polyhaven.com/a/grass_medium_01) — CC0.

Aircraft, modular shapes, character parts and impostor arrangements are authored for Pineapple Siege. Editable sources and scripts are in `art/` and `scripts/`.

Three.js and its Meshopt adapter: MIT. Basis Universal texture transcoder: Apache-2.0; license texts are packaged beside the decoder.

[Sound recordings and attribution](audio/CREDITS.md).

Animated impact plumes: [Smoke particles by Kenney](https://kenney.nl/assets/smoke-particles) — CC0-1.0. Puff variants are cross-faded and expanded in the game; original files and license are in `art/particles/source/`.

Pineapple rind: custom artwork generated for Pineapple Siege using the built-in image generator. This is not a scanned CC0 material. The source image, prompt and source/runtime hashes are retained in `art/materials/pineapple-skin-v1.provenance.json`; runtime texture is packaged locally.
